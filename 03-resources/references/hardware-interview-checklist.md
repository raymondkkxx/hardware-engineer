# 硬件工程师高频面试考点速查清单

> **用法**：不规定顺序，按需自查。遇到不熟的直接点进对应 Wiki 或让 AI 用工程例子给你讲透。

## 一、无源器件与基础电路
- [ ] 电阻：封装与功率降额（0402/0603/0805 额定功率）、0Ω 电阻的 5 种常见用途、采样电阻四线开尔文接法
- [ ] 电容：MLCC 的**直流偏压效应（DC Bias）**、温度特性（X7R/X5R/C0G/NP0 区别）、铝电解/钽电容失效模式
- [ ] 电感与磁珠：电感 $I_{sat}$ 与 $I_{rms}$ 区别；磁珠在 100MHz 下的阻抗参数与直流电阻 DCR
- [ ] 二极管：肖特基（低 $V_F$、快恢复但漏电流大）、TVS（$V_{RWM}$ / $V_{BR}$ / $V_C$ 选型）、稳压管（Zener）
- [ ] 上下拉电阻、RC 充放电时间常数 $\tau = RC$ 与低通/高通截止频率 $f_c = \frac{1}{2\pi RC}$

## 二、晶体管与运放
- [ ] BJT 三极管：NPN/PNP 开关电路、饱和条件、下拉/加速电容作用
- [ ] MOSFET：NMOS vs PMOS 导通条件、高边驱动为什么要用自举电路（Bootstrap）或 PMOS、$R_{DS(on)}$ 与结温关系、米勒效应（Miller Plateau）
- [ ] 运放：虚短/虚断、同相/反相/差分放大公式、输入失调电压 $V_{os}$、压摆率 $SR$、增益带宽积 $GBW$、容性负载振荡补偿

## 三、电源设计（必考重灾区）
- [ ] LDO vs Buck：效率估算、压差（Dropout）、PSRR、轻载纹波与散热计算 $P = (V_{in}-V_{out}) \cdot I_{out}$
- [ ] Buck 电路：电感电流连续（CCM）与断续（DCM）模式、电感感值与纹波电流关系、SW 节点振铃原因与抑制
- [ ] 电源时序（Power Sequencing）与防倒灌、热插拔浪涌电流（Inrush Current）抑制（缓启动 Soft Start）

## 四、数字电路与总线
- [ ] 建立时间（Setup Time）与保持时间（Hold Time）物理意义
- [ ] 推挽输出 vs 开漏输出（Open-Drain）；线与（Wired-AND）逻辑
- [ ] I2C：上拉电阻为什么通常选 2.2kΩ~10kΩ？（总线电容 $C_b$ 与上升时间 $t_r$ vs 灌电流能力）
- [ ] SPI：4 种模式、片选与高速反射问题
- [ ] UART / RS485 / CAN：差分信号抗共模干扰原理、120Ω 终端电阻作用
- [ ] 晶振：负载电容 $C_L$ 计算公式 $C_L = \frac{C_1 \cdot C_2}{C_1 + C_2} + C_{stray}$、起振失败常见原因

## 五、PCB Layout、SI/PI、EMC 与调试
- [ ] 去耦电容摆放原则与回流路径（Return Path）最小化
- [ ] 为什么高速信号线不能跨地平面分割？
- [ ] 示波器测电源纹波的正确姿势（带宽限制 20MHz、AC 耦合、接地弹簧、1X 探头）
- [ ] ESD / 浪涌防护布局要点（TVS 紧靠接口、保护地与数字地隔离/单点连接）
