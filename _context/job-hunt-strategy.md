# 高效求职策略菜单 (Job Hunt Strategy Menu)

> **用法**：这不是时间表，而是一份**按 ROI 排序的模块菜单**。你当前缺哪块、想冲哪块，直接挑对应模块下手。

---

## 模块 A：先让简历过筛（最快见效）
- **核心逻辑**：HR 和用人经理（HM）看一份硬件简历通常不超过 30 秒，他们只扫三个东西：**用过什么平台/芯片、画过几层板/解决过什么指标、实测过什么问题**。
- **高杠杆动作**：
  - 把“参与了某某板卡设计”改成**量化指标 + 故障闭环**（如：负责 STM32H7 + 4 层板设计，将电源纹波从 120mV 压到 18mV，解决 I2C 丢包问题）。
  - 附带一页纸的**作品集 PDF / GitHub 链接**（原理图截图 + PCB 3D 图 + 示波器实测波形图），杀伤力远超纯文字。
- **入口**：[[01-projects/resume-and-portfolio/project-overview]]

## 模块 B：项目“防拷打”深挖（决定能否过一面/二面）
- **核心逻辑**：硬件面试 70% 的时间都在挖你简历上写过的项目。只要你对自己画的每一根线、选的每一个电容电阻都能自圆其说，基本稳过一半。
- **高杠杆动作**：
  - 挑出简历里最核心的 1~2 个项目，用 [[03-resources/templates/project-deep-dive-template]] 过一遍“为什么选这颗芯片 / 电容耐压和降额算过没 / 如果板子不上电怎么查”。
  - 随时召唤 [[05-skills/commands/mock-grill]] 让 AI 模拟面试官连环追问。

## 模块 C：高频基础题极速扫雷（防止基础题翻车）
- **核心逻辑**：不需要把《模电》《数电》从头啃一遍，只需要集中扫掉面试必考的 20 个核心考点（如：三极管/MOSFET 开关损耗、运放虚短虚断与稳定性、LDO vs DC-DC 选型、I2C 上拉电阻计算、去耦电容摆法、ESD/EMC 常见措施）。
- **入口**：[[03-resources/references/hardware-interview-checklist]] & [[06-wiki/wiki-index]]

## 模块 D：非常规 / 激进突围（弯道超车可选）
- **如果你不想走海投拼学历的老路，可以考虑**：
  - **定向拆解投递**：找目标公司正在招人的产品，直接做一份针对他们痛点的技术分析或改进 Demo 附在投递邮件里。
  - **48 小时极速硬核 Demo**：如果手头项目太水，用最短时间画一块有亮点的核心板/功能板（或把开源硬核项目彻底吃透复现+实测波形），直接作为敲门砖。
  - **沙盒推演**：用 [[03-resources/templates/radical-idea-sandbox-template]] 或 [[05-skills/commands/pitch-idea]] 快速评估落地路径。
