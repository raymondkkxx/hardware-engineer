# 常用器件选型与避坑速查表 (Cheatsheet)

## 1. MLCC 陶瓷电容（面试最容易阴沟翻船）
- **直流偏压效应（DC Bias）**：高介电常数电容（X5R / X7R）在加上直流电压后，**实际有效容值会大幅缩水**！比如一颗 10uF / 6.3V 的 0402 X5R 电容，加 5V 直流电压后可能只剩 1.5uF~2uF。
  - **工程对策**：耐压至少留 **2 倍以上降额**（5V 轨选 16V/25V），或者大封装、或者查厂商偏压曲线。
- **温漂材质**：
  - **C0G / NP0**：几乎无温漂、无偏压效应，适合晶振负载电容、精密 RC 滤波、PLL 环路。
  - **X7R / X5R**：容量大，适合电源去耦与储能（X7R 耐温到 125°C，X5R 到 85°C）。
  - **Y5V**：温漂极差，工程上尽量别用。

## 2. MOSFET 选型关键参数
- **$V_{DS}$**：留 1.5~2 倍耐压裕量（考虑开关关断时的感性尖峰）。
- **$V_{GS(th)}$ vs 实际驱动电压**：千万别看 $V_{GS(th)} = 1.5\text{V}$ 就以为 3.3V GPIO 能完全导通它！必须看手册里的 **$R_{DS(on)}$ 测试条件**（比如标的是 $V_{GS} = 4.5\text{V}$ 还是 $10\text{V}$）以及输出特性曲线。
- **$Q_g$（栅极总电荷）**：高频开关（如 DC-DC、电机驱动）重点看 $Q_g$，直接决定驱动损耗与开关速度；纯静态负荷开关则重点看 $R_{DS(on)}$。

## 3. 无源晶振（Crystal）
- **负载电容匹配公式**：$C_L = \frac{C_1 \cdot C_2}{C_1 + C_2} + C_{stray}$
  - 其中 $C_{stray}$ 为 PCB 走线与引脚寄生电容（通常估算 3~5pF）。
  - 例：晶振要求 $C_L = 12\text{pF}$，估算 $C_{stray} = 4\text{pF}$，则 $\frac{C_1 C_2}{C_1 + C_2} = 8\text{pF}$，取 $C_1 = C_2 \approx 16\text{pF}$（选标准值 15pF 或 18pF）。
- **Layout 要点**：紧贴 MCU，下方严禁走任何信号线（最好第二层局部挖空或保持完整干净参考地），外围包地并打过孔。

## 4. 磁珠（Ferrite Bead）
- **参数看 100MHz 阻抗值**（如 600Ω @ 100MHz）、**额定电流**（留足降额，大电流会导致磁饱和使阻抗骤降）和 **DCR**（直流压降）。
- **别乱用在电源大电流主干道上**：注意负载瞬态电流冲击引起的压降和 LC 谐振（磁珠 + 电容可能产生谐振尖峰）。
