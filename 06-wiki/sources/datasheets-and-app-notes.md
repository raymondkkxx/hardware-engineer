# 高价值硬件资料源与参考清单 (Sources)

> 遇到具体芯片或电路吃不准时，直接查一线原厂的 Application Note，比搜博客靠谱 10 倍。

## 1. 必藏原厂应用笔记（App Notes）
- **TI（德州仪器）**：
  - *AN-1149 / SLVA477*：Buck 开关电源功率级计算与 PCB Layout 黄金法则
  - *SLYT294 / Op Amps for Everyone*：运放稳定性与常见电路大全
- **ADI（亚德诺）**：
  - *MT-031 / MT-101*：接地实践与去耦技术权威指南
- **ST（意法半导体）**：
  - *AN2867*：STM32 振荡器设计指南（晶振起振与负载电容计算圣经）
  - *AN4488 / AN5031*：STM32 硬件开发入门与 PCB 布局规范

## 2. 高效在线工具
- **TI WEBENCH Power Designer**：输入输入/输出电压和电流，1 分钟生成完整 Buck/Boost 原理图、BOM 和效率仿真，参考价值极高。
- **Saturn PCB Toolkit**（免费桌面小工具）：算走线载流、过孔电流、差分阻抗、爬电距离。
- **立创开源硬件平台（OSHWHub）**：急需找成熟模块参考电路或做速成 Demo 时直接翻高星开源项目。
