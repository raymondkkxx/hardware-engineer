# 电源完整性（PI）、去耦电容与 LDO/DC-DC 权衡

## 1. 面试必杀题：为什么芯片电源引脚旁边要放 10uF + 1uF + 0.1uF？
- **初级回答**：“大电容滤低频，小电容滤高频。”（面试官听了一般会继续追问“为什么大电容滤不了高频？”）
- **硬核工程回答**：
  1. 实际电容存在**等效串联电感（ESL）**和**等效串联电阻（ESR）**，它在自谐振频率 $f_0 = \frac{1}{2\pi\sqrt{LC}}$ 之后会变成**电感**，阻抗随频率升高而变大。
  2. 大容值电容（如 10uF，常见较大封装）ESL 较大，谐振频率低；小容值、小封装电容（如 0402 0.1uF）ESL 小，谐振频率高，能在几十到上百 MHz 维持低阻抗。
  3. **多容值并联的物理本质**：在宽频段内压低电源分配网络（PDN）的阻抗，为芯片内部逻辑门高速翻转提供瞬态电流（$\Delta I / \Delta t$），防止电源轨塌陷（Voltage Droop）。
  4. **进阶注意点（加分项）**：不同容值并联会在两个谐振点之间产生**反谐振尖峰（Anti-resonance Peak）**，合理利用电容的 ESR 或同容值多颗小封装并联有时比盲目混用容值更稳。

## 2. 去耦电容 PCB 布局铁律
- **先经过电容焊盘，再进入芯片电源引脚**（如果先连芯片再拉线到电容，去耦效果大打折扣）。
- **过孔紧贴电容焊盘**（或双过孔打在焊盘两侧），尽量缩短到地平面的回流环路，减小安装电感（Mounting Inductance）。

## 3. LDO vs Buck（DC-DC）选型权衡

| 维度 | LDO（线性稳压器） | Buck（开关降压） |
| :--- | :--- | :--- |
| **效率** | $\eta \approx \frac{V_{out}}{V_{in}}$，压差大时效率极低、发热严重 | 通常 85%~95%+，适合大压差、大电流 |
| **纹波与噪声** | 极低，无开关噪声，高频 PSRR 压制纹波 | 存在开关纹波与高频振铃（SW 节点） |
| **外围与成本** | 仅需输入输出电容，面积小 | 需要功率电感、二极管/同步管、自举电容等 |
| **经典组合** | **Buck 预降压 + LDO 二级稳压**：兼顾高效率与模拟/RF/ADC 低噪声供电 |

## 4. Buck 电路面试高频追问
- **功率环路（Hot Loop）是哪一圈？**
  - 上管 + 下管（或续流二极管） + 输入去耦电容构成的脉冲电流环路。PCB 上必须做到**面积最小**，否则辐射 EMI 爆表、SW 节点振铃严重。
- **自举电容（Bootstrap Cap）干嘛用的？**
  - 当上管使用 NMOS 时，导通需要 $V_G > V_S + V_{GS(th)}$，而导通时 $V_S \approx V_{in}$，所以需要自举电容在 SW 为低时充电，SW 拉高时把栅极驱动电压“抬举”到 $V_{in} + V_{drive}$ 以上。
