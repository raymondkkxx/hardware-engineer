# 常见通信总线硬件坑与计算 (I2C / SPI / UART / RS485 / CAN)

## 1. I2C 总线
- **为什么必须加上拉电阻？**
  - I2C 的 SDA 和 SCL 都是**开漏输出（Open-Drain）**，只能拉低不能主动输出高电平，靠上拉电阻拉高（实现多主机线与仲裁和不同电平兼容）。
- **上拉电阻怎么算？（面试高频）**
  - **下限（不能太小）**：受限于芯片 IO 的最大灌电流能力 $I_{OL}$（通常 3mA），$R_{p(\min)} = \frac{V_{DD} - V_{OL(\max)}}{I_{OL}}$（例如 3.3V 下约 $1\text{k}\Omega$）。
  - **上限（不能太大）**：受限于总线总寄生电容 $C_b$ 与协议规定的最大上升时间 $t_r$（如 100kHz 标准模式 $t_r \le 1000\text{ns}$，400kHz 快速模式 $t_r \le 300\text{ns}$），近似公式 $R_{p(\max)} \approx \frac{t_r}{0.8473 \cdot C_b}$。
  - **经验值**：3.3V 系统短距板内通常选 **2.2kΩ ~ 4.7kΩ**；长线或负载多时减小阻值或加 I2C Buffer。
- **常见坑**：从机死锁把 SDA 一直拉低 -> 主机发 9 个 SCL 时钟脉冲解锁，或硬件断电复位。

## 2. SPI 总线
- **高速下的振铃问题**：SPI 是推挽输出，边沿很陡。频率上到几十 MHz 时，如果走线较长，容易在时钟沿出现过冲/振铃导致误触发。
  - **解法**：在**源端（输出端）串联 22Ω ~ 33Ω 阻尼电阻**做源端串联端接。
- **MISO 多从机冲突**：确认未选中从机的 MISO 在 CS 拉高时是否真正进入高阻态（Hi-Z）。

## 3. RS485 与 CAN 总线
- **为什么要加 120Ω 终端电阻？**
  - 匹配双绞线特征阻抗（通常 120Ω），消除信号在总线末端的**反射**（尤其是长线高速通信时）。只在**总线物理两端**各加一个 120Ω，中间节点不要加！
- **RS485 失效保护偏置电阻**：
  - 当总线上所有发送器都处于高阻态（空闲）时，A/B 线差分电压接近 0V，容易受噪声误触发。通过 A 上拉到 VCC、B 下拉到 GND（如各 4.7kΩ~10kΩ，或芯片自带 Failsafe），确保空闲时逻辑为 1。
- **隔离与防护**：工业现场（长线/电机旁）必须加 **TVS + 共模电感 + 气体放电管/自恢复保险丝**，必要时用隔离收发器（或数字隔离器 + 隔离电源）切断地环路电位差。
