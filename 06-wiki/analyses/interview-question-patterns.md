# 硬件面试官出题套路与连环追问链

> 理解面试官在想什么，比背 100 道题更有用。面试官的核心诉求只有一个：**“把你招进来画板子/调板子，我会不会天天给你擦屁股？”**

## 常见连环追问链（提前准备好防御）

### 追问链 1：从一颗电容开始
1. “你这个 3.3V 电源输入口放了 10uF 和 0.1uF，为什么？” -> （去耦、PDN 宽频低阻）
2. “你这颗 10uF 选的什么封装和耐压？0402 6.3V？” -> （坑在这里！考 **DC Bias 直流偏压效应**，3.3V 下 6.3V 0402 容值暴跌）
3. “这颗电容摆在 PCB 哪里？离芯片多远？” -> （考**最小化回流环路**、先过电容再进芯片引脚）

### 追问链 2：从 Buck 电源开始
1. “我看你用了一颗 24V 转 5V 的 Buck，电感怎么选的？” -> （纹波电流 $\Delta I_L$ 取输出电流的 20%~40%，算 $L$，再看 $I_{sat}$ 必须大于峰值电流 $I_{out} + \frac{\Delta I_L}{2}$ 且留裕量）
2. “如果板子上电后这颗 Buck 芯片特别烫，可能是什么原因？” -> （输入/输出短路、电感饱和导致电流尖峰、续流二极管/MOSFET 选型 $R_{DS(on)}$ 过大或开关损耗大、PCB 散热铜皮/过孔不够）
3. “用示波器测它的输出纹波，怎么测才准？” -> （**20MHz 带宽限制、AC 耦合、拔掉长鳄鱼夹改用接地弹簧**）

### 追问链 3：开放故障排查
- **“新打样回来的板子，插上电源没反应，你第一步干嘛？”**
  - 忌讳上来就说“看代码”或“拿示波器点芯片”。
  - 标准工程回答：**先断电目检（连锡/极性/虚焊） -> 万用表蜂鸣档/电阻档测各路电源对地阻抗排除短路 -> 限流稳压电源上电看电流变化 -> 逐级量电源电压 -> 查复位与晶振 -> 再上调试器。**
