# 能力域：实验室仪器与硬件 Debug 实战

> **定位**：面试官问“板子不通你怎么查”时，能给出条理清晰、先低风险后高风险的排查链。

## 核心知识地图
1. **新板 Bring-up 标准安全流程（防冒烟指南）**
   - 上电前：**目检**（连锡、极性、虚焊） -> **万用表测各电源对地阻抗**（确认无短路）
   - 首次上电：使用**限流稳压电源**（预设合理限流值），手摸/热成像监测异常发热
   - 电源确认：逐级测量各路电压（纹波、上电时序） -> 确认复位与晶振起振 -> 烧录测试程序
2. **示波器高级实战（面试常考）**
   - **探头接地弹簧** vs 长鳄鱼夹（测电源纹波为什么不能用长接地线？——引入环路电感拾取开关噪声）
   - 1X 与 10X 探头衰减比对带宽、输入电容及纹波测量的影响
   - 触发设置（边沿触发、单次触发 Single 抓上电时序/偶发毛刺、脉宽触发、总线协议解码）
3. **常见硬件故障定位套路**
   - 芯片发烫 / 电源拉低 -> 拆磁珠/0欧电阻分段隔离、红外热成像/酒精法定位短路点
   - 通信偶发丢包 -> 抓眼图/边沿振铃/上拉过弱/地弹噪声/共模干扰
