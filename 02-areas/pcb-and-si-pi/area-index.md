# 能力域：PCB Layout、SI/PI 与 EMC/EMI

> **定位**：区分“能连线”和“懂工程”的分水岭，也是大厂硬件面试必挖领域。

## 核心知识地图
1. **层叠结构与参考平面**
   - 4 层板经典叠层（Signal - GND - Power - Signal）及优缺点
   - 为什么不能跨分割走线（回流路径 Return Path 与环路电感）
2. **电源完整性（PI）与去耦**
   - 大中小电容配合（0.1uF + 1uF + 10uF）的真正物理意义（不是“滤不同频率”那么简单，而是反谐振与低阻抗 PDN）
   - 去耦电容摆放原则（先过焊盘再进芯片引脚、过孔就近打在焊盘旁）
   - 详见：[[06-wiki/concepts/power-integrity-and-decoupling]]
3. **信号完整性（SI）基础**
   - 特征阻抗概念与 50Ω 单端 / 90Ω、100Ω 差分线控阻抗
   - 3W 原则（串扰抑制）、蛇形走线（等长匹配）与包地处理误区
   - 端接方式（源端串联端接 vs 终端并联端接）
4. **EMC / EMI 与防护设计**
   - ESD（静电）、Surge（浪涌）、EFT（群脉冲）防护器件选型与布局（TVS 放接口最前端，先经 TVS 再到被保护芯片）
   - 接地策略（单点接地、多点接地、PGND 与 AGND/GND 处理、机壳地与信号地隔离/电容跨接）
   - 详见：[[06-wiki/concepts/emc-esd-and-grounding]]
