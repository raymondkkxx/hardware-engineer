# 项目：高含金量硬件 Demo 速成（可选）

> **适用场景**：如果你觉得自己现有简历上的项目太单薄（比如只有课程设计或流水灯），与其花几个月从零啃理论，不如用最短时间**做出/复现并深度吃透一个有面试含金量的硬核小板子**。

## 1. 什么叫“有面试含金量”的 Demo？
不需要做很复杂的产品，只要一块 4 层小板能同时覆盖面试官最爱问的几个点：
- **电源树**：Type-C PD / 12V 输入 -> 同步 Buck (5V/3.3V) + 低噪声 LDO (模拟供电)，带过流/防反接/TVS 保护。
- **主控与总线**：主流 MCU（如 STM32G4 / H7 或 ESP32-S3）+ 至少两种高速/差分外设（如 CAN-FD、RS485 隔离、USB HS、SPI Flash/屏幕、高精度 ADC 采样）。
- **可量化实测**：自己焊接/调试通，并用示波器抓出上电时序、开关纹波、总线波形、温升数据。

## 2. 激进速成打法（供参考）
- **参考设计改造法**：直接基于 TI / ST / 开源社区（立创开源/GitHub）的成熟参考设计做二次裁剪与合并，把精力花在**吃透每一颗器件的选型计算**和**打样实测 Debug** 上。
- 用 [[03-resources/templates/radical-idea-sandbox-template]] 记录你的板子构想，随时开干。
