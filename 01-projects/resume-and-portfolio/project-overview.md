# 项目：硬件工程师简历与作品集打磨

> **目标**：让简历在 15 秒内抓住用人经理眼球，并附带可直接证明动手能力的硬件作品集。

## 1. 硬件简历高分公式（拒绝流水账）
不要写：“负责公司某某产品的硬件开发与调试。”  
要写：**`[动作] + [核心器件/平台/拓扑] + [量化指标/难点] + [实测验证结果]`**

### 改写示例
- **电源类**：独立完成 24V 转 5V/3.3V（3A）同步 Buck 电源模块设计，通过优化功率环路面积与去耦电容布局，将满载输出纹波控制在 22mVpp 以内，转换效率达 92%（实测热成像最高温升 28°C）。
- **数字/MCU 类**：基于 STM32H743 完成 4 层工业控制主板原理图与 PCB Layout，解决 400kHz I2C 长线通信丢包及电机启停导致系统复位问题，批量样机一次性通过 ±8kV 接触静电测试。

## 2. 一页纸作品集（Portfolio）杀手锏
如果投递附件允许，强烈建议准备一份 2~4 页的《硬件工程作品集 PDF》（或 GitHub 仓库）：
- **原理图局部截图**：展示你的画图规范（网络标号清晰、模块化分块、注释完整）。
- **PCB Layout 3D 图 / 关键走线截图**：展示你的铺铜、过孔、差分线、功率环路处理能力。
- **示波器实测波形图**：哪怕是测上电时序、SPI 时钟边沿、Buck 开关节点 SW 振铃，只要有真实仪器截图，直接秒杀 80% 只会纸上谈兵的候选人。
